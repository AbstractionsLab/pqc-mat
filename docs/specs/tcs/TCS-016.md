# Verify standalone container deployment

## Preconditions
1. Docker engine running.

## Setup
1. In the project root directory, build the standalone image from the CLI:
```bash
docker build -t vector -f Dockerfile .
```
2. Create a results folder in the project root directory:
```bash
mkdir results
```

## Test steps

1. Run the VECTOR-Code scanner via a standard `docker run` invocation, mounting the test repository as source and the local results directory over the CLI's output path:
```bash
docker run --rm \
  --user "$(id -u):$(id -g)" \
  -v $(pwd)/tests/data/mixed_repo:/src \
  -v $(pwd)/results:/output \
  vector code /src --name my-app --output /output
```
2. Run the VECTOR-Network scanner via a standard `docker run` invocation, mounting the local results directory over the CLI's output path:
```bash
docker run --rm \
  --user "$(id -u):$(id -g)" \
  -v $(pwd)/results:/output \
  vector network --target github.com --protocol ssh --port 22 --output /output

docker run --rm \
  --user "$(id -u):$(id -g)" \
  -v $(pwd)/results:/output \
  vector network --target github.com --protocol tls --port 443 --output /output
```
3. Run the VECTOR-Score to generate a risk report:
```bash
docker run --rm \
  --user "$(id -u):$(id -g)" \
  -v $(pwd)/results:/output \
  vector score /output/github.com_ssh_cbom.json

docker run --rm \
  --user "$(id -u):$(id -g)" \
  -v $(pwd)/results:/output \
  vector score /output/github.com_tls_cbom.json

docker run --rm \
  --user "$(id -u):$(id -g)" \
  -v $(pwd)/results:/output \
  vector score /output/cbom/crypto-combined-cbom.json
```

## Expected outcome

1. The VECTOR-Code scan finishes successfully:
```bash
ls results/
```

  - The `results/` folder on the host contains the following, confirming output was written via the mount:
    - `cbom/`: containing the `crypto-combined-cbom.json` file
    - `databases/`: with folders `db-cpp` and `db-python`
    - `results/`: containing two SARIF files, one for C++ and one for Python

2. The VECTOR-Network scan finishes successfully and the `results/` folder on the host contains the resulted CBOM files for both TLS and SSH protocols:
```bash
ls results/ | grep tls
ls results/ | grep ssh
```

3. The VECTOR-Score successfully generates the risk report for VECTOR-Code and VECTOR-Network CBOM outputs.
```bash
ls results/ | grep risk_report
ls results/cbom | grep risk_report
```
