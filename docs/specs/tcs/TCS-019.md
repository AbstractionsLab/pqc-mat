# Verify VECTOR-Code source input and stop scan

## Preconditions
1. Docker Engine running.
2. `vector.sh` is executable:
```bash
chmod +x vector.sh
```
3. If there is a `env: 'bash\r': No such file or directory` error when running `./vector.sh`, run this command:
```bash
sed -i 's/\r$//' vector.sh
```
This error is due to CRLF endings, which is not supported in Unix.
4. Outbound network access to `github.com`.


## Test steps

1. Run VECTOR GUI:
```bash
./vector.sh gui
```

2. Verify a local folder scan:

2.1. Clone a small sample project in the endpoint where the browser will be opened:
```bash
git clone --depth=1 https://github.com/pyca/cryptography
```

2.2. In the browser, open `New Scan` and click `Choose folder…` and select the cloned folder in the dialog that opens. Accept the pop-up alert. Click `Start scan`, and wait for the scan to finish.

3. Verify a GitHub repository URL scan:

3.1. In `New Scan`, click the `GitHub repository` toggle.

3.2. Enter `https://github.com/pyca/cryptography` as the Source, click `Start scan`, and wait for the scan to finish.

4. Verify Stop scan terminates a running scan, and Scan history reports it correctly afterward:

4.1. Start a new scan: `New Scan` → `VECTOR-Network` → `TLS` → Target `github.com`, Port `443` → `Start scan`. The scan detail page shows "Scan in progress…". While in progress, open a second browser tab and navigate to `Scan history`. Back on the first tab, click `Stop scan`. Check the live output panel and the `Status` field on the scan detail page.


## Expected outcome

2.1. The repository clones successfully.

2.2. The scan is created and the browser navigates to its scan detail page. The scan proceeds through language detection, CodeQL database creation, crypto queries, and CBOM generation. Then the Results page shows a CBOM.

3.1. The `GitHub repository` toggle becomes active, and the input field appears.

3.2. The scan is created and the browser navigates to its scan detail page. When the scan finishes, a Results page with CBOM output appears.

4.1. The scan is created and the browser navigates to its scan detail page. The second tab loads Scan history, and show the scan status `Running`. The `Stop scan` button immediately disables and its label changes to "Stopping…", a message "Stop requested …" appears. The scan's `Status` column shows a gray `stopped` badge.
